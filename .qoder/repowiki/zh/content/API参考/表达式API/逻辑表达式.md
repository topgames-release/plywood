## 简介
逻辑表达式是Plywood查询语言的核心组成部分，用于构建复杂的条件查询和数据过滤规则。本API文档详细解释了布尔逻辑表达式（and、or、not）和比较表达式（大于、小于、等于、in、contains等）的实现细节，包括接口定义、参数类型、返回值以及优化策略。

## 布尔逻辑表达式
布尔逻辑表达式用于组合多个条件，支持and、or、not三种基本操作。

### And表达式
And表达式实现逻辑与操作，当所有操作数都为真时返回真。该表达式具有交换律和结合律特性。

## 短路求值机制
逻辑表达式实现了短路求值机制，以提高执行效率。

### And表达式的短路求值
当And表达式的任意操作数为假时，立即返回假，不再计算后续操作数。

```mermaid
flowchart TD
Start([And表达式求值]) --> CheckFirst["检查第一个操作数"]
CheckFirst --> IsFalse1{"第一个操作数为假?"}
IsFalse1 --> |是| ReturnFalse["返回假"]
IsFalse1 --> |否| CheckSecond["检查第二个操作数"]
CheckSecond --> IsFalse2{"第二个操作数为假?"}
IsFalse2 --> |是| ReturnFalse
IsFalse2 --> |否| ReturnTrue["返回真"]
ReturnFalse --> End([结束])
ReturnTrue --> End
```

**Diagram sources**
- [andExpression.ts](file://src/expressions/andExpression.ts#L90-L110)

### Or表达式的短路求值
当Or表达式的任意操作数为真时，立即返回真，不再计算后续操作数。

```mermaid

CheckFirst --> IsTrue1{"第一个操作数为真?"}
IsTrue1 --> |是| ReturnTrue["返回真"]
IsTrue1 --> |否| CheckSecond["检查第二个操作数"]
CheckSecond --> IsTrue2{"第二个操作数为真?"}
IsTrue2 --> |是| ReturnTrue
IsTrue2 --> |否| ReturnFalse["返回假"]
ReturnTrue --> End([结束])
```

## 表达式简化规则
逻辑表达式在执行前会进行自动简化，以提高执行效率。

### And表达式简化
- `X and false` 简化为 `false`
- `X and true` 简化为 `X`
- `false and X` 简化为 `false`
- `true and X` 简化为 `X`

```mermaid
flowchart TD
Start([And表达式简化]) --> IsFalse{"表达式是否等于false?"}
IsFalse --> |是| ReturnFalse["返回false"]
IsFalse --> |否| IsTrue{"表达式是否等于true?"}
IsTrue --> |是| ReturnOperand["返回操作数"]
IsTrue --> |否| IsAndExpression{"操作数是否为And表达式?"}
IsAndExpression --> |是| MergeExpressions["合并表达式"]
IsAndExpression --> |否| TryMerge["尝试合并"]
MergeExpressions --> ReturnSimplified["返回简化后的表达式"]
TryMerge --> ReturnSimplified
ReturnFalse --> End([结束])
ReturnOperand --> End
ReturnSimplified --> End
```

## 性能优化建议
为提高逻辑表达式的执行性能，建议遵循以下优化策略。

### 表达式顺序优化
将计算成本低且可能为假的条件放在And表达式的前面，以利用短路求值机制。

```mermaid
flowchart TD
Start([表达式顺序优化]) --> IdentifyCost["识别各条件的计算成本"]
IdentifyCost --> IdentifyLikelihood["识别各条件为假的可能性"]
IdentifyLikelihood --> SortConditions["按成本和可能性排序"]
SortConditions --> PlaceLowCost["将低成本条件放在前面"]
PlaceLowCost --> PlaceHighFalse["将高可能性为假的条件放在前面"]
PlaceHighFalse --> OptimizeExpression["优化后的表达式"]
OptimizeExpression --> End([结束])
```

### 避免重复计算
使用表达式简化和缓存机制避免重复计算相同的子表达式。

```mermaid
flowchart TD

IdentifySubexpressions --> ExtractCommon["提取公共子表达式"]

ReuseResult --> OptimizePerformance["优化性能"]
```

### 实际代码示例
```typescript
// 使用Expression.and()构建复杂查询
const complexFilter = Expression.and([
  $('age').greaterThan(18),
  $('status').is('active'),
  $('region').in(['north', 'south']),
  $('score').greaterThanOrEqual(80)
]);

// 使用Expression.or()构建多条件查询
const searchQuery = Expression.or([
  $('name').contains('john', 'ignoreCase'),
  $('email').contains('john', 'ignoreCase'),
  $('phone').contains('john')
]);
```
