## 引言
本文档深入解析了`Dataset`类中提供的核心聚合方法，包括`count`、`sum`、`average`、`min`、`max`和`countDistinct`。这些方法是数据分析和处理的核心，允许用户对数据集执行基本的统计计算。文档将详细阐述每种方法的计算逻辑、空值处理策略以及它们如何与强大的Expression系统集成以支持复杂的计算。此外，还将提供实际的使用示例和在大规模数据集上的性能优化建议。

## 核心聚合方法

### 计数 (count)
`count`方法是最基础的聚合函数，用于计算数据集中数据行（datum）的总数。其计算逻辑非常直接，即返回`Dataset`内部`data`数组的长度。

**数学定义**:
`count = |D|`
其中 `D` 是数据集。

**空值处理策略**: 该方法不涉及对具体数据值的检查，因此不受空值（null）或未定义值（undefined）的影响。它计算的是所有数据行的数量，无论这些行中的字段是否为空。

**数值稳定性**: 由于该操作仅涉及一次内存访问以获取数组长度，因此具有极高的数值稳定性和性能。

### 求和 (sum)
`sum`方法用于计算指定表达式在所有数据行上求值结果的总和。

**数学定义**:
`sum = Σ(expr(d)) for d in D`
其中 `expr(d)` 是表达式在数据行 `d` 上的求值结果。

**实现逻辑**: 该方法首先通过`ex.getFn()`获取一个计算函数（`ComputeFn`），然后遍历数据集中的每一行，应用该函数并累加结果。

**空值处理策略**: 代码实现中没有显式处理空值。如果表达式求值结果为`null`或`undefined`，在JavaScript中`null`和`undefined`在加法运算中会被转换为`0`（`null + 1 = 1`, `undefined + 1 = NaN`）。因此，`null`值会被当作`0`处理，而`undefined`值会导致最终结果为`NaN`。

**数值稳定性**: 对于大规模数据集，简单的累加可能会因浮点数精度问题而累积误差。然而，该实现并未采用如Kahan求和等更高级的数值稳定算法，因此在处理大量浮点数时可能存在精度损失。

### 平均值 (average)
`average`方法计算指定表达式在所有数据行上求值结果的算术平均值。

**数学定义**:
`average = sum / count`
其中 `sum` 是`sum`方法的结果，`count` 是`count`方法的结果。

**实现逻辑**: 该方法复用了`sumFn`和`count`方法。它首先计算总和，然后除以数据行数。如果数据集为空（`count`为0），则返回`null`。

**空值处理策略**: 与`sum`方法相同，依赖于底层`sumFn`的行为。`null`值被当作`0`计入总和，`undefined`值会导致总和为`NaN`，从而使平均值也为`NaN`。

**数值稳定性**: 该方法的稳定性依赖于`sum`方法。对于非常大的数据集，先求和再相除的策略可能会导致溢出或精度问题。一个更稳定的替代方案是在线算法（online algorithm），但当前实现并未采用。

### 最小值 (min)
`min`方法用于找出指定表达式在所有数据行上求值结果的最小值。

**数学定义**:
`min = min{expr(d) for d in D}`

**实现逻辑**: 该方法初始化一个`min`变量为`Infinity`，然后遍历每一行数据，将表达式求值结果与当前的`min`值进行比较，如果更小则更新`min`。

**空值处理策略**: 代码中没有对`null`或`undefined`进行特殊处理。在JavaScript中，`null`在与数字比较时会被转换为`0`，而`undefined`与任何数字比较的结果都是`false`。因此，如果数据中包含`undefined`，`min`的值将始终为`Infinity`，因为`undefined < Infinity`为`false`。`null`值会参与比较。

**数值稳定性**: 该操作是稳定的，因为它只涉及比较操作，不涉及可能导致精度损失的算术运算。

### 最大值 (max)
`max`方法用于找出指定表达式在所有数据行上求值结果的最大值。

**数学定义**:
`max = max{expr(d) for d in D}`

**实现逻辑**: 与`min`方法类似，该方法初始化一个`max`变量为`-Infinity`，然后遍历每一行数据，将表达式求值结果与当前的`max`值进行比较，如果更大则更新`max`。

**空值处理策略**: 与`min`方法完全相同。`null`值会被当作`0`参与比较，而`undefined`值会导致`max`的值始终为`-Infinity`。

**数值稳定性**: 该操作是稳定的。

### 去重计数 (countDistinct)
`countDistinct`方法用于计算指定表达式在所有数据行上求值结果的不同（distinct）值的数量。

**数学定义**:
`countDistinct = |{expr(d) for d in D}|`
即求值结果集合的基数。

**实现逻辑**: 该方法使用一个JavaScript对象（`seen`）作为哈希表来跟踪已经遇到的值。遍历每一行数据，对表达式求值，如果该值在`seen`对象中不存在，则将其加入并增加计数器。

**空值处理策略**: `null`和`undefined`被视为不同的值。例如，如果数据行中既有`null`也有`undefined`，它们会被计为两个不同的值。`NaN`是一个特殊情况，因为`NaN !== NaN`，所以每次遇到`NaN`都会被当作一个新值，这可能导致计数偏高。

**数值稳定性**: 该操作是稳定的，因为它不涉及算术运算。但其内存消耗与不同值的数量成正比，在处理高基数（high-cardinality）列时可能成为瓶颈。

## 与Expression系统的集成

### 新旧调用方式对比
`Dataset`的聚合方法（如`sum`, `average`）支持两种调用方式，但旧式方式已被弃用。

- **旧式调用 (已弃用)**: 直接传入一个函数。
  ```javascript
  // 已弃用
  dataset.sum(function(d) { return d.price; });
  ```
  当使用这种方式时，代码会发出警告，并通过`sumFn`方法执行。

- **新式调用 (推荐)**: 传入一个`Expression`对象。
  ```javascript
  // 推荐
  dataset.sum($('price'));
  ```
  这种方式利用了`Expression`系统，提供了更强大、更安全和更可组合的API。

**Section sources**
- [dataset.ts](file://src/datatypes/dataset.ts#L714-L723)

### Expression系统的优势
通过`Expression`系统，聚合方法可以支持极其复杂的输入参数，而不仅仅是简单的列引用。

1.  **复杂表达式作为输入**: 可以将任何`Expression`作为聚合函数的参数。例如，可以对两个字段的和进行求和：
    ```javascript
    dataset.sum($('price').add($('tax')));
    ```
    这比在应用阶段先计算`price + tax`再求和更加高效和灵活。

2.  **表达式组合与复用**: `Expression`对象是不可变的，可以轻松地组合、修改和复用。例如，可以定义一个复杂的表达式并将其用于多个聚合：
    ```javascript
    const profitExpr = $('revenue').subtract($('cost'));
    const totalProfit = dataset.sum(profitExpr);
    const avgProfit = dataset.average(profitExpr);
    ```

3.  **SQL生成与优化**: `Expression`系统可以将复杂的聚合操作序列转换为高效的SQL查询。例如，`$('data').sum($('price'))`会被转换为`SUM(price)`。更重要的是，系统可以进行优化，如`sum`方法的`distribute`函数可以将`sum(lhs + rhs)`分解为`sum(lhs) + sum(rhs)`，从而在查询层面进行优化。

## 实际应用示例

### 指标统计
在业务监控场景中，聚合方法常用于计算关键绩效指标（KPI）。

```javascript
// 假设有一个销售数据集
const salesDataset = Dataset.fromJS([
  { product: 'A', sales: 100, region: 'North' },
  { product: 'B', sales: 150, region: 'South' },
  { product: 'A', sales: 200, region: 'North' },
]);

// 计算总销售额
const totalSales = salesDataset.sum($('sales')); // => 450

// 计算平均销售额
const avgSales = salesDataset.average($('sales')); // => 150

// 计算不同产品的数量
const productCount = salesDataset.countDistinct($('product')); // => 2
```

### 分布分析
在用户行为分析中，可以结合`split`和聚合方法来分析数据分布。

```javascript
// 按地区拆分数据集
const regionalSales = salesDataset.split({ region: '$region' }, 'salesData');

// 计算每个地区的总销售额
const regionalTotals = regionalSales.apply('totalSales', $('salesData').sum($('sales')));

// 计算每个地区的平均销售额
const regionalAverages = regionalTotals.apply('avgSales', $('salesData').average($('sales')));
```

## 性能优化建议

1.  **避免在循环中调用聚合方法**: 如果需要对同一数据集进行多次聚合，应确保数据集没有被修改。`Dataset`是不可变的，但创建新的`Dataset`实例有开销。尽量将多个聚合操作合并或在单次遍历中完成。

2.  **利用Expression的优化**: 尽可能使用`Expression`对象而不是函数。`Expression`系统可以进行静态分析和优化，例如将`sum(a + b)`分解为`sum(a) + sum(b)`，这可以在数据库层面并行执行。

3.  **注意高基数列的countDistinct**: `countDistinct`方法使用哈希表，其内存占用与不同值的数量成正比。对于高基数列（如用户ID），在内存中计算可能不切实际。应考虑使用近似算法（如HyperLogLog）或在数据源（如Druid）中进行计算。

4.  **预过滤数据**: 在进行聚合之前，使用`filter`方法移除无关数据，可以显著减少计算量。
    ```javascript
    // 优于先聚合再处理
    const recentSales = dataset.filter($('date').greaterThan('2023-01-01'));
    const totalRecentSales = recentSales.sum($('sales'));
    ```

5.  **理解空值影响**: 明确了解`null`和`undefined`在计算中的行为。如果需要不同的处理方式（例如，将`null`排除在`min`/`max`计算之外），应在表达式中显式处理，例如使用`fallback`或`is`表达式。

## 结论
`Dataset`类提供的聚合方法是构建数据分析应用的基石。它们通过与`Expression`系统的深度集成，从简单的数值计算演变为支持复杂逻辑和查询优化的强大工具。理解每种方法的计算逻辑、空值处理方式和性能特征，对于编写高效、可靠的代码至关重要。遵循最佳实践，如使用`Expression`对象和预过滤数据，可以确保在处理大规模数据集时获得最佳性能。
