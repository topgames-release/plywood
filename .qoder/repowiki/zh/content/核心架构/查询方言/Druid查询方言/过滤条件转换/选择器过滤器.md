## 引言
选择器过滤器是Plywood与Druid集成中的关键组件，负责将Plywood表达式转换为Druid查询过滤器。该机制通过druidFilterBuilder实现，支持多种过滤器类型，包括选择器、区间、正则表达式等。选择器过滤器在数据查询过程中起到精确筛选数据的作用，其性能直接影响查询效率。

**选择器过滤器**的核心功能是将Plywood中的布尔表达式转换为Druid原生过滤器结构，同时处理时间维度、维度映射和提取函数等复杂场景。该转换过程需要考虑Druid的查询限制和数据模型特性。

## 等值比较表达式转换
等值比较表达式通过IsExpression类实现，该类处理Plywood中的等值比较操作。转换过程首先检查表达式类型，然后根据右侧表达式的类型决定生成何种过滤器。

```mermaid
sequenceDiagram
participant Plywood表达式 as Plywood表达式
participant DruidFilterBuilder as DruidFilterBuilder
participant makeSelectorFilter as makeSelectorFilter
participant makeInFilter as makeInFilter
Plywood表达式->>DruidFilterBuilder : filterToDruid()
DruidFilterBuilder->>DruidFilterBuilder : timelessFilterToFilter()
DruidFilterBuilder->>DruidFilterBuilder : 处理IsExpression
alt 右侧为集合类型
DruidFilterBuilder->>makeInFilter : 调用makeInFilter
makeInFilter-->>DruidFilterBuilder : 返回in过滤器
else 右侧为单值类型
DruidFilterBuilder->>makeSelectorFilter : 调用makeSelectorFilter
makeSelectorFilter-->>DruidFilterBuilder : 返回selector过滤器
end
DruidFilterBuilder-->>Plywood表达式 : 返回Druid过滤器
```

## 复杂引用降级处理
当表达式涉及复杂引用时，系统会降级使用expression filter。这种降级处理通过makeExpressionFilter方法实现，将Plywood表达式转换为Druid表达式过滤器。

```mermaid
sequenceDiagram

Expression->>DruidFilterBuilder : 尝试生成选择器过滤器

DruidFilterBuilder->>DruidExpressionBuilder : expressionToDruidExpression()
DruidExpressionBuilder-->>DruidFilterBuilder : 返回Druid表达式
DruidFilterBuilder->>DruidFilterBuilder : 创建expression过滤器
DruidFilterBuilder-->>Expression : 返回expression过滤器
```

## 性能优化建议
选择器过滤器的性能优化主要集中在减少expression filter的使用。应尽量使用简单的维度引用和等值比较，避免复杂的表达式组合。对于时间维度，应优先使用时间区间过滤而非表达式过滤。

| 优化策略 | 说明 | 适用场景 |
|--------|------|--------|
| 避免复杂表达式 | 使用简单维度引用而非复杂表达式 | 所有过滤场景 |
| 优先使用选择器 | 选择器过滤器性能优于表达式过滤器 | 等值比较 |
| 合理使用提取函数 | 减少不必要的提取函数嵌套 | 字符串处理 |
| 时间维度优化 | 使用时间区间而非表达式 | 时间过滤 |
| 避免JavaScript | JavaScript过滤器性能较差 | 复杂逻辑 |

## 常见错误排查
常见错误主要包括不可分割指标过滤、复杂表达式转换失败等。错误排查应首先检查指标的unsplitable属性，然后验证表达式的复杂度。

```mermaid
flowchart TD
Start([开始]) --> CheckErrorType["检查错误类型"]
CheckErrorType --> IsUnsplitable{"不可分割指标?"}
IsUnsplitable --> |是| CheckAggregation["检查是否已聚合"]
IsUnsplitable --> |否| CheckComplexity["检查表达式复杂度"]
CheckAggregation --> ReviewQuery["重新设计查询"]
CheckComplexity --> IsComplex{"表达式复杂?"}
IsComplex --> |是| SimplifyExpression["简化表达式"]
IsComplex --> |否| CheckMapping["检查维度映射"]
SimplifyExpression --> End([结束])
CheckMapping --> End
ReviewQuery --> End
```
