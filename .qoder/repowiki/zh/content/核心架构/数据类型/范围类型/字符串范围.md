## 简介
字符串范围（StringRange）是Plywood中用于表示字符串类型数据范围的核心数据结构。它继承自通用的Range类，专门用于处理字符串类型的区间操作，支持字典序比较和范围包含判断。字符串范围在文本数据查询、前缀匹配和字典区间扫描等场景中发挥着重要作用。

## 创建方法
字符串范围提供了多种创建方式，包括从JavaScript对象创建和从字符串直接创建。

### 从JavaScript对象创建
静态方法`fromJS`用于从JavaScript对象创建字符串范围实例。该方法接受一个包含start、end和可选bounds属性的对象参数。

```mermaid

ExtractParams --> ValidateTypes["验证start和end为字符串"]
ValidateTypes --> CreateInstance["创建StringRange实例"]
CreateInstance --> ReturnInstance["返回新实例"]
```

## 序列化与比较
字符串范围支持序列化为JavaScript对象以及与其他字符串范围进行比较。

### 序列化
`toJS`方法将字符串范围实例序列化为JavaScript对象。该方法会省略默认的边界值，只在边界不为默认值时包含bounds属性。

```mermaid

CreateJSObject --> CheckBounds["检查bounds是否为默认值"]
CheckBounds --> |不是默认值| AddBounds["添加bounds属性"]
CheckBounds --> |是默认值| SkipBounds["跳过bounds属性"]
AddBounds --> ReturnJS["返回JS对象"]
SkipBounds --> ReturnJS
```

## 范围操作
字符串范围支持多种范围操作，包括扩展、并集和交集计算。

### 扩展操作
`extend`方法计算两个字符串范围的扩展范围。该方法返回包含两个范围的最小范围。

```mermaid
flowchart TD
Start([extend调用]) --> GetEndpoints["获取两个范围的起点和终点"]
GetEndpoints --> DetermineStart["确定新的起点"]
DetermineStart --> |thisStart < otherStart| UseThisStart["使用thisStart"]
DetermineStart --> |otherStart < thisStart| UseOtherStart["使用otherStart"]
DetermineStart --> |相等| UseEither["使用任一起点"]
DetermineStart --> DetermineEnd["确定新的终点"]
DetermineEnd --> |thisEnd > otherEnd| UseThisEnd["使用thisEnd"]
DetermineEnd --> |otherEnd > thisEnd| UseOtherEnd["使用otherEnd"]
DetermineEnd --> |相等| UseEitherEnd["使用任一终点"]
DetermineStart --> CreateNewRange["创建新范围实例"]
DetermineEnd --> CreateNewRange
CreateNewRange --> ReturnRange["返回新范围"]
```

## 应用场景
字符串范围在多种数据查询场景中都有重要应用。

### 文本数据查询
字符串范围可用于查询特定字典序范围内的文本数据。例如，查询以特定字母开头的所有条目。

### 前缀匹配
通过设置适当的范围边界，字符串范围可以用于实现前缀匹配功能。例如，查找以"abc"开头的所有字符串。

### 字典区间扫描
字符串范围支持高效的字典区间扫描操作，可用于在有序字符串集合中快速定位数据。


## 限制与替代方案
字符串范围有一些特定的限制，需要了解并采取相应的替代方案。

### 不支持中点计算
字符串范围不支持中点计算，调用midpoint方法会抛出错误。

```mermaid
flowchart TD
Start([midpoint调用]) --> ThrowError["抛出错误：midpoint not supported in string range"]
```

**Diagram sources **
- [stringRange.ts](file://src/datatypes/stringRange.ts#L80-L82)

### 替代方案
对于需要中点计算的场景，可以考虑以下替代方案：
1. 使用数值范围代替字符串范围
2. 实现自定义的字符串中点计算逻辑
3. 将字符串转换为数值进行计算
