## ⚡ 常用命令速查

```bash
# 编译
npm run compile          # 完整编译
./compile-tsc           # 仅编译 TypeScript
./compile-pegjs         # 仅编译 PEG.js

# 测试
npm test                # 运行标准测试
npm run full-test       # 运行完整测试
./run-coverage          # 检查覆盖率
mocha test/expression/* # 运行特定测试

# 开发工作流
git checkout -b feature/description  # 创建功能分支
npm run compile                      # 编译
npm test                             # 运行测试
git push origin feature/description  # 推送分支
# 创建 Pull Request
```

## 💡 最佳实践速记

### 代码简洁性
- 函数尽量小（单一职责）
- 避免深层嵌套（最多 3 层）
- 使用提前返回减少嵌套

### 类型安全
- 禁止使用 `any` 类型
- 显式类型注解
- 使用泛型提高复用性

### 测试覆盖
- 单元测试 ≥ 80%
- 关键路径 ≥ 95%
- 边界条件必须测试

### 性能优化
- 使用 subtotalsSpec 优化查询
- 避免内存泄漏
- 使用流式处理大数据集

### 文档维护
- 类和公共方法必须有 JSDoc
- 复杂逻辑需要注释
- 新功能必须更新文档
